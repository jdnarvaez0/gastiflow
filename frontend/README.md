# Gastiflow Frontend

This is the Nuxt.js frontend for Gastiflow.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## Directory Structure

- `app.vue`: Main application component.
- `nuxt.config.ts`: Nuxt configuration.
- `package.json`: Dependencies and scripts.
